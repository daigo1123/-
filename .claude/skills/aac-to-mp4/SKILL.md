# 音声ファイルを YouTube 用 mp4 に変換する

## なぜ変換が必要か

YouTube は音声だけのファイルを受け付けない。`.aac` をそのままアップロードすると
「認識できないファイル形式です」で弾かれる。拡張子を `.mp4` に書き換えても中身が
音声のみなので同じく失敗する。つまり必要なのは**映像トラックを足した本物の mp4** で、
これが同梱スクリプトのやることになる。

## 使い方

```bash
python3 scripts/aac_to_mp4.py 入力.aac
```

同じ場所に `入力.mp4` ができる。既定は 1920x1080 / 30fps / 濃紺の単色背景。
変換後に自動で検証が走り、最後に「YouTube にそのままアップロードできます。」と
出れば完了。ユーザーには出力先のパスを伝えること。

`-o` を付けなければ入力と同じフォルダに同名 `.mp4` で出力される。入力が
すでに `.mp4` の場合だけ `_youtube` が付く（元ファイルを壊さないため）。

## オプション

| オプション | 既定値 | 用途 |
|---|---|---|
| `-o PATH` | 入力と同名の .mp4 | 出力先を指定する |
| `--color 色` | `#0B1220`(濃紺) | 背景色。`#RRGGBB` でも `black` などの色名でも可 |
| `--image PATH` | なし | 単色の代わりに静止画を敷く。比率は保ったまま余白を背景色で埋める |
| `--resolution WxH` | `1920x1080` | 縦動画なら `1080x1920` |
| `--fps N` | `30` | 1〜60 |
| `--audio モード` | `auto` | `auto` / `copy`(無劣化) / `reencode`(必ず変換) |
| `--bitrate 値` | `320k` | 再エンコード時のみ有効 |

奇数の解像度を渡しても自動で偶数に丸められる（yuv420p は偶数でないと成立しないため）。

## 音声の扱い

既定の `auto` は入力の中身を ffprobe で見てから決める。

- **AAC-LC / 44.1kHz か 48kHz / 1〜2ch** → そのままコピー。再エンコードしないので
  音質は一切落ちず、処理も速い
- それ以外（mp3、5.1ch、22kHz、HE-AAC など）→ AAC-LC 48kHz ステレオに変換

つまり、そのままで通る音源には触らず、通らない音源だけ直す。ユーザーが
「音質を絶対に落としたくない」と言う場合も、既定のままで問題ないと伝えてよい。
逆に「とにかく確実に通したい」なら `--audio reencode` を勧める。

## スクリプトが保証していること

変換後に ffprobe で出力を読み直し、次を1つずつ確認する。1つでも落ちれば
エラー終了するので、「OK が並んだ = アップロードして弾かれない」と考えてよい。

- 映像トラックがある（音声のみは YouTube が受け付けない）
- 映像が H.264 / ピクセル形式が yuv420p / 解像度が偶数
- 音声トラックがあり、コーデックが AAC
- 再生時間が 0 でなく、元の音声と食い違っていない（変換中の取りこぼし検出）
- moov が先頭にある（faststart。再生開始が速くなる）

検証で NG が出たときは、その項目をユーザーに伝えたうえで `--audio reencode` を
試すこと。音声側の特殊な形式が原因であることが多い。

## 処理時間の目安

映像は最初から最後まで同じ絵なので、音声の長さに比例して伸びる。

- 単色背景: 10分の音声で 1分弱、1時間の音声で 5分前後
- `--image` 指定時: 絵の情報量ぶん重くなり、上記の3倍程度

1時間超の音源を渡されたときは、先に「数分かかります」と伝えてから実行する。

## つまずきやすいところ

**ffmpeg が入っていない** — スクリプトが OS ごとのインストールコマンドを表示して
止まる。案内に従ってもらう（macOS は `brew install ffmpeg`）。

**「読み取れませんでした」と出る** — ffprobe の実際のエラーを併記しているので、
その内容をユーザーに伝える。ffmpeg のバージョンが古くて新しい形式に対応して
いないケースが多く、更新で直ることがある。

**動画ファイルを渡された** — 既に映像が入っている場合は警告を出したうえで、
元の映像を捨てて背景を作り直す。ユーザーが元の映像を残したかった可能性が
あるので、実行後に一言確認すること。

## 変換後に伝えること

ファイルができたら、出力パスとサイズに加えて次を添えると親切。

- YouTube Studio の「作成 > 動画をアップロード」にこの mp4 をそのまま投げればよい
- サムネイルは別途 YouTube 側で設定できる（背景画像とは別物）
- 公開前に「限定公開」で1本上げて再生確認するのが安全
