# 上級医への質問文スキル

看護師さんからの依頼と自分の考え（メモ書きでOK）を、上級医の先生にそのまま送れる質問文に整える。

## 出力フォーマット

```
{患者名}さんなのですが

①{質問1}

②{質問2}
```

### お手本（この文面に寄せる）

```
かね〇さんなのですが

①持参薬のビオフェルミンは飲ませる形で大丈夫でしょうか？

②低用量ピルについては本人管理で大丈夫でしょうか？それとも看護師サイドで管理させたほうが良いでしょうか？
```

## 書き方のルール

1. **書き出し**は「{患者名}さんなのですが」の1行だけにする。挨拶（お疲れ様です等）や締め（よろしくお願いします等）は入れない。
   - 患者名は入力に書かれた表記（伏せ字含む）をそのまま使う。名前がなければ「〇〇さんなのですが」とする。
2. **質問は①②③…と番号を付け**、質問ごとに空行を1行入れる。1つの質問は1〜2文で短く書く。
   - 1つの依頼に複数の論点があれば番号を分ける。質問が1つだけでも①を付ける。
3. **自分の考えを「〜する形で大丈夫でしょうか？」の確認形にする。** 上級医が「はい／いいえ」で答えられる形が基本。
   - 自分の方針が決まっている → 「{方針}で大丈夫でしょうか？」
     例: 「持参薬のビオフェルミンは飲ませる形で大丈夫でしょうか？」
   - 2択で迷っている → 「{第一案}で大丈夫でしょうか？それとも{第二案}のほうが良いでしょうか？」
     自分が推す案（なければ看護師さんの提案に近い方）を先に書く。
   - 自分の考えが入力にない → 「{論点}はどうしたら良いでしょうか？」
4. **背景は判断に必要な分だけ**、質問文の頭に短く入れる。
   - 例: 「本日から絶食ですが、朝の持参薬（〇〇）は内服させる形で大丈夫でしょうか？」
   - 「看護師さんから〜と相談があり」は、看護師さんからの相談だと伝える必要があるときだけ書く。
   - バイタル・検査値などの数値は、入力にあるものだけをそのまま使う。
5. 敬語は丁寧語（〜でしょうか、〜ほうが良いでしょうか）にそろえる。くだけすぎず、硬すぎない。
   - 「させたほうが」「飲ませる形で」「本人管理で」など、病棟で普段使う言い回しはそのまま残す。
6. **事実や医学的な判断を足さない。** 入力にない薬剤名・用量・数値・方針を補わない。
   - 質問に欠かせない情報（薬剤名、用量、時刻など）が抜けている場合は、本文に【要確認：〇〇】と入れて残す。
7. 実名・ID・生年月日など個人を特定できる情報が入力にあっても、自分から増やしたり補ったりしない。

## 出力のしかた

- コピペしやすいよう、質問文だけをコードブロックに入れて出す。
- 【要確認】を入れた場合や、論点を分けたり並べ替えたりした場合だけ、コードブロックの下に1〜2行で補足する。それ以外の前置き・解説は書かない。

## 変換例

**入力:**
> かね〇さん。看護師さんから、持参薬のビオフェルミンどうしますかって聞かれた。続けていいと思う。あと低用量ピル飲んでて、本人管理にするか聞かれた。本人管理でいいと思うけど、看護師管理の方がいいのかも迷う。

**出力:**
```
かね〇さんなのですが

①持参薬のビオフェルミンは飲ませる形で大丈夫でしょうか？

②低用量ピルについては本人管理で大丈夫でしょうか？それとも看護師サイドで管理させたほうが良いでしょうか？
```

**入力:**
> やま〇さん、今夜眠れないって看護師さんから。不眠時指示が入ってない。自分はレンボレキサント5mgでいいかなと思う。あと明日CTあるけど朝食止めるか聞かれた、止めていいと思う

**出力:**
```
やま〇さんなのですが

①不眠時の指示が入っていないのですが、レンボレキサント5mgで指示を入れる形で大丈夫でしょうか？

②明日CTがあるのですが、朝食は止める形で大丈夫でしょうか？
```
