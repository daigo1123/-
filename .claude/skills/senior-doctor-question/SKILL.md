# 上級医への質問文作成（スタッフ伝言板 → LINE）

## 使う場面

研修医（ユーザー）が、看護師からスタッフ伝言板に書かれた依頼・確認事項を、
上級医のいるLINEグループ（例：「総1 研修医＆…」）に投げる質問文に変換する。

上級医は移動中や外来中にスマホで読む。**スクロールせずに読めて、
「はい/いいえ」または一言で返せる**ことが最重要。

## 入力として想定するもの

- スタッフ伝言板のスクリーンショット（電子カルテ画面の写真）
- 伝言板の書き起こしテキスト
- ユーザーの口頭メモ（「◯◯さんの安静度、血栓あるけど今のままでいいか聞きたい」）

伝言板は次の形で並んでいる：

```
2026/09/08 10:18 研修医:内科一般:加藤舞  [2026/12/01まで表示]
以下お願いいたします。
□口腔内環境不良です。ご家族の希望もあり歯科コンサルいかがでしょうか。
□るい痩、褥瘡あり。食事摂取1割程度です。NST介入いかがでしょうか？
■右足に血栓ありますが、安静度指示は今のままでよろしいでしょうか
 →抗凝固薬飲んでいるので付き添い歩行可にしました
```

- `□` = 未対応（これから上級医に聞く）
- `■` = 対応済み（`→` に結論が書かれている。**質問文に含めない**）
- 1件の投稿に複数項目が入る。日付が新しい順に並ぶ。

## 手順

### 1. 項目を洗い出して仕分ける

伝言板から項目を全部拾い、3つに分ける。

| 分類 | 例 | 扱い |
|---|---|---|
| **上級医の判断が要る** | 安静度変更、コンサル依頼（歯科・NST・皮膚科等）、処方変更、検査追加、輸液内容、方針・IC | 質問文にする |
| **研修医/看護師で完結** | 爪切り持参依頼、家族来棟時の物品、日々の創部観察 | 質問文に入れない（ユーザーに「これは自分で対応でよさそう」と一言添える） |
| **すでに解決済み** | `■` 付き、`→` で結論が出ている項目 | 除外。ただし「◯◯は付き添い歩行可にしました」と**報告**として1行入れるかはユーザーに確認 |

判断に迷う項目は勝手に落とさず、ユーザーに「これも入れますか？」と聞く。

### 2. 各項目を「現状 → 根拠 → 依頼」に組み立てる

これが文型の核。

```
【現状】現在「〇〇」となっておりますが、
【根拠】△△のため、
【依頼】□□したほうがよろしいでしょうか。
```

- **現状**：カルテ上の現在の指示を、原文のまま `「 」` で引用する
  （例：「痛み/覚醒度に応じて離床可」）。指示文言が不明なら**推測せずユーザーに聞く**。
- **根拠**：なぜ今聞くのか。所見・検査・家族希望など事実だけ（例：血栓あるため／食事摂取1割程度、るい痩・褥瘡あり／ご家族の希望もあり）。
- **依頼**：上級医が可否で返せる形で閉じる。
  - 変更の可否 →「〜変更したほうがよろしいでしょうか。」
  - 現状維持の確認 →「〜は今のままでよろしいでしょうか。」
  - コンサル →「〜コンサルいかがでしょうか。」
  - 介入依頼 →「〜介入いかがでしょうか。」

### 3. 文面に組み立てる

**1項目のとき**（例文と同じ形）：

```
お疲れ様です。
ナガ○ワさんの安静度について、現在「痛み/覚醒度に応じて離床可」となっておりますが、血栓あるため安静度変更したほうがよろしいでしょうか。
```

**複数項目のとき**（患者ごとにまとめ、項目は箇条書き）：

```
お疲れ様です。
ナガ○ワさんについて2点ご相談です。

・口腔内環境不良で、ご家族の希望もあり歯科コンサルいかがでしょうか。
・るい痩、褥瘡あり、食事摂取1割程度です。NST介入いかがでしょうか。
```

**複数患者のとき**：患者ごとに改行で区切る。3人を超えるなら分割送信を勧める。

## 文面のルール

- 冒頭は必ず `お疲れ様です。` で始め、次の行から本文（改行して1行空けない）。
- **患者名は伏字**。カタカナ表記にして1文字を `○` に置換する（長川 → `ナガ○ワ`、田中 → `タ○カ`）。フルネームは使わない。実名が入力されたら必ず伏せる。
- 敬体（です・ます）。「〜でしょうか。」で締め、`?` は使わず `。` で閉じる。
- 3〜4行以内。長い経過説明・鑑別の考察は書かない（聞かれたら答える）。
- 絵文字・スタンプ・過度なクッション言葉（「お忙しいところ大変恐縮ですが」等）は入れない。
- 略語は病棟で通じるものはそのまま（NST、IC、DVT、Ope、ADL）。通じにくいものは開く。
- 依頼を1文に2つ以上詰めない。2つあるなら箇条書きにする。

## やってはいけないこと

- **医学的判断を代行しない**。「血栓があるので安静にすべきです」のような結論・推奨を文面に書かない。事実を並べて判断を仰ぐ形に留める。
- **伝言板にない情報を足さない**。検査値、既往、内服内容などを補完・創作しない。必要なら「この値は分かりますか？」とユーザーに聞く。
- 患者の実名・ID・部屋番号をそのまま出さない。
- 看護師の書いた原文の意味を変えて要約しない（特に数値と現行指示の文言）。

## 出力の形

1. **そのままコピペできる文面**をコードブロックで提示する
2. その下に、必要なら短く添える：
   - 質問文に入れなかった項目とその理由（「爪切りの件は自分で対応でよさそうです」）
   - 埋められなかった箇所（「現在の安静度指示の文言が分からないので、カルテの表記に置き換えてください」）
3. 複数案は出さない。1案を出して、直しの要望を受ける。
