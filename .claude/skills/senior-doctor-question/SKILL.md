# 上級医への質問文スキル

看護師さんからの依頼と自分の考え（メモ書きでOK）を、上級医の先生にそのまま送れる文面に整える。
`/senior-doctor-question` や `/joui` のあとにメモが付いていれば、そのメモ（$ARGUMENTS）を入力として変換する。メモが付いていなければ、看護師さんからの依頼と自分の考えを送ってもらうよう一言だけ返す。

文面は内容に応じて **A：短い確認型** と **B：丁寧な相談型** のどちらかを使う。

## どちらの型を使うか

| 型 | 使う場面 |
|---|---|
| **A：短い確認型** | 背景説明がほぼ要らない、はい／いいえで済む確認。持参薬を続けるか、薬の管理方法、食止めの有無など。確認したいことが複数並ぶときも A。 |
| **B：丁寧な相談型** | バイタル変化・症状・検査異常など、経過や自分のアセスメントを伝えてから判断を仰ぐ相談。新しい指示（報告基準、頓用指示など）を提案するときや、治療方針に関わるとき。 |

- 迷ったら、背景を2文以上書かないと伝わらない内容なら B、そうでなければ A。
- ユーザーが「短く」「丁寧に」「A で」「B で」などと指定したら、それに従う。

---

## A：短い確認型

### フォーマット

```
{患者名}さんなのですが

①{質問1}

②{質問2}
```

### お手本

```
かね〇さんなのですが

①持参薬のビオフェルミンは飲ませる形で大丈夫でしょうか？

②低用量ピルについては本人管理で大丈夫でしょうか？それとも看護師サイドで管理させたほうが良いでしょうか？
```

### ルール

1. 書き出しは「{患者名}さんなのですが」の1行だけにする。挨拶や締めの言葉は入れない。
2. 質問は①②③…と番号を付け、質問ごとに空行を1行入れる。1つの質問は1〜2文で短く書く。質問が1つでも①を付ける。
3. 自分の考えを、上級医がはい／いいえで答えられる確認の形にする。
   - 方針が決まっている → 「{方針}で大丈夫でしょうか？」
   - 2択で迷っている → 「{第一案}で大丈夫でしょうか？それとも{第二案}のほうが良いでしょうか？」（自分が推す案を先に書く。なければ看護師さんの提案に近い方を先に書く）
   - 自分の考えが入力にない → 「{論点}はどうしたら良いでしょうか？」
4. 背景は、判断に必要な分だけ質問の頭に短く入れる（例：「明日CTがあるのですが、朝食は止める形で大丈夫でしょうか？」）。

---

## B：丁寧な相談型

### フォーマット

```
お疲れ様です。

{患者名}さんについてご相談したいことがあります。

{何が起きているか}、看護師より{依頼内容}について指示の依頼がありました。

{自分のアセスメント・現在の状態}。

「{提案する指示}」

という指示にしたいと考えておりますが、いかがでしょうか？

よろしくお願いします。
```

### お手本

```
お疲れ様です。

い◯さんについてご相談したいことがあります。

夜間にHR40台まで低下することがあり、看護師より12誘導心電図撮影の基準について指示の依頼がありました。

HR低下は一時的で、胸部症状やバイタルの著変は認めておりません。

「HR40台が数分以上持続した場合は12誘導心電図を撮影し、担当医へ報告。」

という指示にしたいと考えておりますが、いかがでしょうか？

よろしくお願いします。
```

### ルール

1. 「お疲れ様です。」で始め、「{患者名}さんについてご相談したいことがあります。」と続ける。最後は「よろしくお願いします。」で締める。
2. 段落は次の順番にし、段落ごとに空行を1行入れる。
   1. 何が起きているか ＋ 看護師さんから何を依頼されたか（1文にまとめる）
   2. 自分のアセスメント・現在の状態（症状の有無、バイタル、一時的か持続しているか など）
   3. 自分の提案
   4. 「いかがでしょうか？」
3. 提案が**指示の文言**のとき：指示文を「」で囲んで独立した段落にし、次の段落を「という指示にしたいと考えておりますが、いかがでしょうか？」にする。指示文は「〜の場合は〜し、担当医へ報告。」のように、条件と対応がわかる体言止め／指示書き調で書く。
4. 提案が**指示の文言ではない**とき（薬の変更、検査の追加など）：「{提案}したいと考えておりますが、いかがでしょうか？」の1文にする。
5. 自分の考えが入力にないとき：提案の段落を省き、「どのように対応したらよろしいでしょうか？」で質問する。
6. 確認したいことが複数あるとき：提案の段落を①②の箇条にし、最後を「以上について、いかがでしょうか？」にする。
7. 文体は「〜があり」「〜を認めておりません」「〜と考えております」などの丁寧なです・ます調にそろえる。

## 両方の型に共通するルール

1. 患者名は入力に書かれた表記（伏せ字含む）をそのまま使う。名前がなければ「〇〇さん」とする。
2. **事実や医学的な判断を足さない。** 入力にない薬剤名・用量・数値・症状の有無・方針を補わない。
   - 「胸部症状なし」「バイタル著変なし」なども、入力に書かれているときだけ書く。
   - 質問に欠かせない情報（薬剤名、用量、時刻、数値など）が抜けている場合は、本文に【要確認：〇〇】と入れて残す。
3. 「看護師さん」は文中では「看護師」と書く（B）。A では看護師さんからの依頼だと伝える必要があるときだけ触れる。
4. 「飲ませる形で」「本人管理で」「担当医へ報告」など、病棟で普段使う言い回しはそのまま残す。
5. 実名・ID・生年月日など個人を特定できる情報を、自分から増やしたり補ったりしない。

## 出力のしかた

- コピペしやすいよう、文面だけをコードブロックに入れて出す。
- 【要確認】を入れた場合や、論点を分けた・並べ替えた場合だけ、コードブロックの下に1〜2行で補足する。それ以外の前置き・解説は書かない。

## 変換例

**入力（A になる例）:**
> かね〇さん。看護師さんから、持参薬のビオフェルミンどうしますかって聞かれた。続けていいと思う。あと低用量ピル飲んでて、本人管理にするか聞かれた。本人管理でいいと思うけど、看護師管理の方がいいのかも迷う。

**出力:**
```
かね〇さんなのですが

①持参薬のビオフェルミンは飲ませる形で大丈夫でしょうか？

②低用量ピルについては本人管理で大丈夫でしょうか？それとも看護師サイドで管理させたほうが良いでしょうか？
```

**入力（B になる例）:**
> い◯さん、夜にHR40台に下がることあるって。看護師さんから12誘導とる基準ほしいって言われた。一時的で胸痛とかないしバイタルも大丈夫。40台が数分続いたら12誘導とって担当医報告、でいいと思う

**出力:**
```
お疲れ様です。

い◯さんについてご相談したいことがあります。

夜間にHR40台まで低下することがあり、看護師より12誘導心電図撮影の基準について指示の依頼がありました。

HR低下は一時的で、胸部症状やバイタルの著変は認めておりません。

「HR40台が数分以上持続した場合は12誘導心電図を撮影し、担当医へ報告。」

という指示にしたいと考えておりますが、いかがでしょうか？

よろしくお願いします。
```
